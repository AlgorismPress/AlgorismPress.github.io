# Algorism Press Web Portal

> **Code to Print, Research to Global Books**

The Algorism Press web portal is the public front door for a developing publishing practice focused on technical, academic, and research-led books.

## What This Portal Represents

Algorism Press is interested in the careful movement from an idea to a readable, durable book. The portal presents that public vision through:

- structured writing and editorial preparation
- clear presentation of code, diagrams, tables, and references
- thoughtful digital and print preparation
- respectful collaboration with authors and researchers

## Current Status

The portal is currently in development. Publication information will be added when individual works are confirmed and ready to share.

## Repository Scope

This repository contains the public web portal only. It intentionally does not include private business strategy, internal production methods, financial models, credentials, or unpublished operational details.

## Run Locally

The portal is a static HTML page. Open `index.html` directly in a browser, or serve this directory with any simple static web server.
